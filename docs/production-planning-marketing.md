## 一、长版（官网功能页 / 公众号推文）

### 标题
**让每一张生产订单，都跑在计划前面**
—— operp 生产计划（MPS + MRP）：从接单到完工入库，一条链路算清楚

### 正文

**你是不是也遇到过这些场景？**

- 销售接了单，车间问什么时候开工，采购问要不要备料 —— 没人答得上来；
- BOM 改了一版，领料单还是按老用量发出去的；
- 月底算成本，材料、人工、制费对不上账，在制金额全靠估。

operp 的生产计划模块，把这些问题变成一条**可复现、可审计、可追溯**的计算链路：

**① 主生产计划（MPS）—— 先定盘子，再开工**

把销售需求汇成主计划，一键确认、整单锁定，谁也改不动已确认的数字。粗能力校验（RCCP）提前告诉你：这个月的工作中心，接得住这批计划吗？确认之后，一行一个产品直接下推成生产订单，台账防重复，下推了多少永远有账可查。

**② 物料需求运算（MRP）—— 该买的买，该做的做**

引擎自动做低层码分层、逐日净需求、批量规则（按批 / 固定量 / 倍数）、提前期倒排，BOM 里的「幻影件」自动穿透。跑完一轮，每一颗物料都有明确答案：什么时候缺、缺多少、是下采购单还是下生产单。

**③ 计划转单 —— 运算结果不落空**

MRP 算出来的计划订单，一键转成采购订单草稿和生产订单，每一条需求都带「转单追踪」，重跑运算绝不会重复下单。转了多少、还剩多少，列表里看得清清楚楚。

**④ 生产执行 —— 单据闭环，账实一致**

领料出库、完工入库一键过账：出库自动取移动加权成本，库存流水带符号可逆，反过账一键退回。BOM 一键展开成领料建议，开工前先做齐套检查 —— 缺料的订单，别让它停在车间门口。

**⑤ 成本卷算 —— 月底不用再"估"**

材料按已过账领料、人工按已确认报工工时、制费按机时费率，自动卷算到产品。本期投入与完工结转一目了然，期末在制余额自动滚入下期。

**⑥ AI 只解读，不替你做主**

运算结果由确定性引擎产出，每个数字都能复现、能审计；AI 在旁边把结果翻译成人话，帮你找出瓶颈物料和风险订单。AI 生成的报告失败也不影响运算 —— 数字永远先于观点。

### 收尾
多租户 SaaS 架构，租户间数据严格隔离；权限按角色收敛，计划员、车间、财务各看各的账。
**operp 生产计划 —— 让计划算得准，让车间跑得动，让成本算得清。**

## 三、一句话版本（按场景取用）

1. **Slogan 向**：让每一张生产订单，都跑在计划前面。
2. **能力向**：从 MPS 到 MRP，从领料到成本，一条链路算清楚。
3. **信任向**：确定性引擎出数，AI 只解读不计算 —— 每个数字都可复现、可审计。
4. **痛点向**：备多少料、何时开工、月底成本 —— 不再靠猜。

## 四、功能亮点速览（PPT / 详情页用）

| 亮点 | 一句话说明 |
|---|---|
| MPS 确认即锁定 | 确认后整单冻结，下推量台账可查，杜绝"计划被随手改" |
| RCCP 粗能力校验 | 下单前先看工作中心接不接得住 |
| MRP 确定性引擎 | LLC 分层 + 逐日净需求 + 批量规则 + 提前期倒排，幻影件自动穿透 |
| 计划转单带追踪 | 一键转 PO/MO，转单状态全程可查，重跑不重复下单 |
| 齐套检查前置 | 开工前先验料，缺料订单进不了车间 |
| 过账即闭环 | 移动加权成本、带符号流水、一键反过账 |
| 成本自动卷算 | 材料/人工/制费自动归集，在制余额跨期滚动 |
| AI 报告兜底 | LLM 只解读不计算，报告失败自动回退确定性摘要 |
| 多租户隔离 | SaaS 架构，数据与权限按租户/角色严格收敛 |
