## 1. 系统概览

### 1.1 这是什么

OPERP 是一套面向制造企业的**多租户、AI 原生 ERP 平台**，覆盖 **财务 / 进销存 / 生产制造** 三大业务域，外加一个可配置的**平台元数据底座**。

它和传统 ERP 的区别在于：**业务单据的"形态、流转规则、审批规则"不是写死的，而是配置出来的**。因此你可以自己加字段、自己画审批流程、自己定义"哪张单能转成哪张单"，也可以让 AI 直接帮你建单、过账、转单。

### 1.2 三大业务域

| 业务域       | 主要用途                                    | 典型角色          |
| --------- | --------------------------------------- | ------------- |
| **财务管理**  | 会计科目、凭证、总账、试算平衡、应收应付、固定资产               | 会计、财务主管       |
| **进销存管理** | 主数据、采购、销售、库存收发存、调拨盘点、批次追溯               | 采购员、销售员、仓管    |
| **生产制造**  | BOM、工艺路线、生产订单、领料报工、完工入库、MRP/MPS、成本核算、委外 | 计划员、车间主管、成本会计 |
| **系统管理**  | 用户、租户、角色、菜单、字典、币别、流程配置、单据转换、报表设计        | 系统管理员         |

### 1.3 六个核心概念（懂了这六个，系统就通了）

| 概念               | 一句话解释                                | 在界面上体现为                  |
| ---------------- | ------------------------------------ | ------------------------ |
| **DocType 单据类型** | "一张单据是什么"的元数据（表名、单号规则、是否可提交、绑定哪个审批流） | 系统管理 → DocType 构建        |
| **Workflow 审批流** | "谁审批、按什么顺序审批"，支持条件分支、多级审批、驳回撤回       | 系统管理 → 流程配置；单据工作台顶部的审批按钮 |
| **DocFlow 单据转换** | "这张单能生成什么单"，声明式字段映射 + 数量台账（防超下推）     | 单据工作台顶部的「下推」按钮           |
| **BAQ 业务活动查询**   | 不写 SQL 的可视化查询设计器：ER 图式拖表勾字段，支持多级 / 多字段 / 非主外键关联 | 系统管理 → BAQ 管理            |
| **页面设计器**        | 拖拽组件拼页面，发布即成为菜单                      | 系统管理 → 页面设计器             |
| **AI 智能体**       | 用自然语言查数据、建单、过账、转单、生成 BAQ             | 右上角 AI 图标                |

### 1.4 多租户与多币别

- **多租户**：一套系统服务多家企业。每家企业的数据**物理隔离**（数据库行级安全策略 + 表权限双层控制），互相看不见。
- **多币别**：单据可同时记录**原币金额**与**本位币金额**，汇率在单据上**冻结**；库存、凭证、报表一律按本位币核算。本位币在「币别管理」中设定，**全局唯一**。

## 2. 快速上手

### 2.1 登录

访问系统地址（生产环境为 `https://operp.oplug.cn`），进入登录页。

| 字段 | 说明             |
| -- | -------------- |
| 邮箱 | 注册时使用的邮箱，即登录账号 |
| 密码 | 至少 6 位         |

> **默认超管账号**：`admin@operp.com` / `admin123`  
> ⚠️ **上线后请立即修改默认密码**。

### 2.2 自助开通企业租户

登录页切到「注册租户」页签，填写：

| 字段             | 说明                                       |
| -------------- | ---------------------------------------- |
| 租户名称           | 如"某某科技有限公司"                              |
| 租户编码           | 如 `acme`，小写字母开头，仅含小写字母/数字/下划线/短横线，2~31 位 |
| 管理员姓名 / 用户名    | 该租户的初始管理员                                |
| 邮箱 / 密码 / 确认密码 | 邮箱将作为登录账号                                |

提交后系统自动完成三件事：**注册登录账号 → 创建企业租户 → 在新租户下创建管理员**，并自动物化该租户的**菜单、角色、字典、币别、表权限**等基线数据。随后即可用该邮箱登录。

> 新建租户默认角色为 **租户管理员（tenant_admin）**，**不会**授予平台超管权限。

## 4. 单据通用操作（核心）

> 📌 **本章是全系统最重要的一章**。所有业务单据（采购、销售、库存、生产、财务）都遵循同一套操作范式，学会一张单，就会用全部单据。

### 4.1 单据列表页

每个单据在菜单里都是一个列表页，标准结构：

| 区域        | 内容                                                       |
| --------- | -------------------------------------------------------- |
| **顶部查询栏** | 关键字搜索（单号/名称）、状态筛选、日期范围等；部分页面还有批量操作按钮（如「过账」「反过账」「下达」「开工」） |
| **工具条**   | 新增、编辑、删除（选中行后可用）                                         |
| **数据表格**  | 支持分页、排序、勾选多行                                             |
| **行操作**   | 双击或点「查看/编辑」打开单据工作台                                       |

### 4.2 单据工作台（SupaModal）

打开一张单据后，会弹出一个大尺寸工作台弹窗，包含：

```
┌─ 标题 [展开/收起] [上一条/下一条] [审批按钮] [下推按钮] [单据连接图] [P/D] [打印] ─┐
│ ┌─ 页签1：单头 ──────────────┬─ 操作日志（时间轴）──────────────┐ │
│ │  表头字段表单（两列布局）    │  谁、什么时候、做了什么操作        │ │
│ │                            ├─ 审批历史（卡片）────────────────┤ │
│ │                            │  各审批节点、审批人、意见、时间     │ │
│ ├─ 页签2：明细 ──────────────┴──────────────────────────────────┤ │
│ │  明细表格 + 新增/编辑/删除明细行                                │ │
│ └──────────────────────────────────────────────────────────────┘ │
│  [底部按钮区：保存 / 取消 / 自定义动作]                            │
└──────────────────────────────────────────────────────────────────┘
```

关键控件说明：

| 控件            | 作用                            |
| ------------- | ----------------------------- |
| **展开/收起**     | 全屏 ↔ 常规尺寸切换                   |
| **上一条 / 下一条** | 不关弹窗，直接在列表内翻单                 |
| **审批按钮**      | 提交 / 通过 / 驳回 / 撤回（见 4.3）      |
| **下推**        | 生成下游单据（见 4.4）                 |
| **单据连接图**     | 查看本单的上游来源与下游去向全链路             |
| **P / D 开关**  | 打印预览（Preview）/ 设计（Design）模式切换 |
| **打印按钮**      | 打开打印模板设计器，可自定义套打模板并保存         |
| **操作日志**      | 本单据的全部操作留痕（含失败原因）             |
| **审批历史**      | 本单据的审批流转记录                    |
| **Esc**       | 关闭弹窗                          |

> 💡 **明细数据在「明细」页签内维护**：新增/修改/删除明细行后，**表头合计（总金额/总数量/总成本）由系统自动重算**，无需手工填写。  
> 💡 **仓库 → 库位联动**：选择仓库后库位下拉自动过滤；切换仓库会清空已选库位；若该仓库只有一个库位则自动带出。

### 4.3 单据生命周期与状态

不同单据的状态略有差异，常见状态如下：

**订单类（采购订单 / 销售订单）**

| 状态          | 含义        | 可执行动作        |
| ----------- | --------- | ------------ |
| 草稿          | 刚建，可随意改   | 编辑、删除、提交审批   |
| 待审批         | 已提交，等待审批  | 通过 / 驳回 / 撤回 |
| 已审批         | 审批通过，可下推  | 下推生成入库单/出货单  |
| 部分收货 / 部分发货 | 下游单据已部分执行 | 继续下推剩余数量     |
| 已收货 / 已发货   | 下游执行完毕    | —            |
| 已关闭 / 已取消   | 终止        | —            |

> ⚠️ **订单类单据不可直接过账**。订单只表达"要买/要卖"，实际出入库必须通过**下推生成入库单/出货单**后过账。

**出入库类（采购入库 / 销售出货 / 采购退货 / 销售退货）**

| 状态      | 含义                     |
| ------- | ---------------------- |
| 草稿      | 可编辑，不影响库存              |
| 待审核     | 已提交审批                  |
| 已审核     | 审批通过，未过账               |
| **已过账** | ✅ **已实际影响库存与总账**，不可再编辑 |
| 已取消     | 作废                     |

> ⚠️ **"过账"是库存与财务真正生效的分水岭**。未过账的单据只是"纸面"，不产生库存流水，也不生成会计凭证。

**凭证**

| 状态      | 含义       |
| ------- | -------- |
| 草稿      | 可编辑      |
| **已过账** | 已进总账，不可改 |
| 已作废     | —        |

> ⚠️ 凭证过账前会校验：**至少两条分录**、**借贷双方金额均大于 0**、**借贷必须平衡**。不平衡会直接拒绝并提示差额。

### 4.4 审批流操作

单据工作台标题栏会根据当前状态显示对应按钮：

| 当前状态   | 可用按钮                     | 说明            |
| ------ | ------------------------ | ------------- |
| 草稿 / 空 | **提交**                   | 提交后进入审批流的第一节点 |
| 待审批    | **通过** / **驳回** / **撤回** | 驳回与撤回会把单据退回   |
| 其他状态   | （无）                      | 本节点已结束        |

- 审批结果会**自动回写单据状态**，审批历史卡片可随时查看每个节点的审批人与意见。
- 若该单据类型**未配置审批流**，会提示"未找到流程定义"，此时单据走简化路径（部分单据可直接点「审核」按钮）。
- **被驳回**的单据可修改后重新提交。

### 4.5 单据转换（下推）

**下推 = 由一张单自动生成下游单据**，并把数量、物料、金额等字段按规则带过去。

系统内置的三条主线：

| 源单   | → 目标单   | 说明       |
| ---- | ------- | -------- |
| 采购订单 | → 采购入库单 | 收货入库     |
| 销售订单 | → 销售出货单 | 发货出库     |
| 生产订单 | → 生产领料单 | 按 BOM 领料 |

使用步骤：

1. 打开已审批的源单（状态需在允许范围内，如"已审批 / 部分收货"）。
2. 点顶部**下推**按钮，弹出下推窗口。
3. 系统按**可转数量**预填每行数量（可手工调整）；数量为 0 的行自动跳过。
4. 确认后生成**目标单草稿**。

关键规则：

- **防超下推**：系统维护"已转数量台账"，累计已转不能超过源单数量。超额会被拒绝。
- **台账只追加不删除**：反冲通过插入负数行实现，任何一行源单都能追溯每一次转换与冲销。
- **生成的单据是草稿**，仍需审批 + 过账才会影响库存。
- 「单据连接图」可直观查看整条链路的上下游关系。

### 4.6 打印模板

- 在某张单据的工作台点 **打印** 按钮 → 进入模板设计器。
- 可用数据源：**主表数据（MainData）+ 明细数据（DetailData）**。
- 支持纸张、方向、页边距、组件拖拽排版。
- 保存后按**单据类型**复用：同一类型的所有单据都用这套模板。
- **P / D 开关**用于在「预览」和「设计」之间切换。

### 4.7 附件与操作日志

| 功能       | 位置          | 说明                                |
| -------- | ----------- | --------------------------------- |
| **业务附件** | 单据工作台 / 详情区 | 上传合同、发票、质检报告等文件                   |
| **操作日志** | 单据工作台右侧时间轴  | 记录新增/修改/删除/过账/反过账等动作，含操作人、时间、失败原因 |
| **系统日志** | 系统管理 → 系统日志 | 全站操作日志总览，可按操作类型、时间、操作人检索          |

## 5. 财务管理

菜单路径：**财务管理**

| 页面         | 路径                          | 用途与要点                                            |
| ---------- | --------------------------- | ------------------------------------------------ |
| **会计科目**   | `/finance/subjects`         | 维护科目表（编码、名称、科目类别、方向）。是凭证与报表的基础                   |
| **凭证管理**   | `/finance/vouchers`         | 录入记账凭证（记账/收款/付款/转账四种类型），支持多币种分录；支持**过账**与**反过账** |
| **总账余额**   | `/finance/gl-balance`       | 各科目期末余额，按期间查询                                    |
| **试算平衡**   | `/finance/trial-balance`    | 借贷平衡校验，支持**本位币**与**按币种**双口径                      |
| **科目/明细账** | `/finance/ledger`           | 单科目的发生额与明细流水                                     |
| **会计期间**   | `/finance/periods`          | 期间开闭管理。**期间关闭后不可再记账**                            |
| **应收账款**   | `/finance/receivables`      | 客户应收台账，状态：未结清 / 部分收款 / 已结清 / 逾期                  |
| **应付账款**   | `/finance/payables`         | 供应商应付台账，状态：未结清 / 部分付款 / 已结清 / 逾期                 |
| **固定资产**   | `/finance/assets`           | 资产卡片、原值、折旧                                       |
| **资产类别**   | `/finance/asset-categories` | 资产分类与折旧规则                                        |

### 5.1 凭证操作要点

1. **新增凭证** → 选择凭证类型、日期、期间，录入借方/贷方分录（至少两条）。
2. 若涉及外币：选择币种后系统会按单据日期**自动带出即期汇率**；取不到汇率时会提示并要求手工填写（**不会**按 1 静默处理）。
3. 保存为草稿 → **过账**。
4. 过账前系统强制校验借贷平衡；过账后凭证进入总账余额与试算平衡表。
5. 需要修改已过账凭证：先**反过账**（凭证退回草稿）→ 修改 → 重新过账。

### 5.2 库存单据自动生成凭证

采购入库、销售出货、采购退货、销售退货、库存调拨、盘点、调整等库存单据**过账时会自动生成对应会计凭证**、并更新总账。

> ⚠️ **重要规则**：若会计侧出现问题（如未配置存货科目映射），系统**不会阻断库存过账**，而是给出**警告**并在返回结果中带上凭证信息。库存业务照常生效，但请及时处理会计侧提示，否则账实会不一致。

### 5.3 多币别与汇兑损益

- **双金额记账**：单据同时记录原币金额与本位币金额；**汇率冻结在单据上**，后续汇率变动不影响已录单据。
- **汇率方向恒定**：`1 单位外币 = rate 单位本位币`。
- **汇兑损益**：包含核销差额与期末调汇，计入 `6603`（净借方为正表示损失）。
- 全站金额展示与输入统一使用系统的金额组件，符号与小数位跟随本位币设置。

**采购订单操作流程**

| **检验管理** | `/mrp/quality`             | 来料检验（IQC）/ 过程检验 / **成品入库检验（FQC）**；判定合格/不合格 |

**生产订单操作流程**

1. 新建生产订单：选择产品、数量、计划日期、BOM、工艺路线、领料仓。
2. **下达**：状态 → 已下达，同时**按工艺路线自动生成工序行**，并按用料明细**预占库存**。
   - 该动作**幂等**：重复点击不会重复生成；工序页签为空时也可以用同一个按钮"补生成工序"。
   - 若产品没有**已启用且在有效期内**的工艺路线（或工序明细为空），会报 `No active routing`。
3. **开工**：状态 → 生产中。
4. **领料**：生成领料单 → 审核 → **过账**（材料库存减少）。
5. **报工**：逐工序录入合格数 / 报废数 / 工时。
6. **完工入库**：生成完工入库单 → 审核 → **过账**（成品库存增加）。
7. 如有剩余材料 → **生产退料**。

> 💡 **批次**：启用批次管理的物料，领料/退料/完工入库明细都支持填批次号，过账时会消费批次。

### 7.6 3D 工厂生产驾驶舱（特色功能）

OPERP 提供一套 **3D 可视化工厂生产驾驶舱**，把车间里的工作中心、在制工单、工序进度、物料齐套、产能负荷等生产数据，投射到一块**可旋转、可缩放、可拖拽布局**的三维车间场景里。这是本系统的特色亮点功能，让你"一眼看到车间正在发生什么"。

**入口**：生产制造 → 生产报表 → 卡片标题栏右侧「**3D 生产驾驶舱**」按钮，点击后以**全屏抽屉**打开。

#### 7.6.1 驾驶舱里能看到什么

| 区域 | 内容 |
| ---- | ---- |
| **3D 场景** | 车间平面：各工作中心（设备）以立体模型摆放在三维坐标上，设备颜色/铭牌随实时状态变化 |
| **顶部 KPI 条** | 平均订单进度、设备运行数（运行 / 总数）、在制订单数、缺料订单数、逾期订单数 |
| **状态图例** | 运行中 / 待机 / 离线 三色图例，各带实时计数 |
| **右侧面板** | 三态切换：在制订单列表 → 订单详情（点订单）/ 设备详情（点设备） |

**设备三态推导口径**（全部从业务事实自动推导，无人工维护字段）：

| 状态 | 含义 | 触发条件 |
| ---- | ---- | ---- |
| 🟢 运行中 | 该工作中心正有活儿在做 | 该工作中心上存在 `in_progress`（进行中）的工序 |
| 🟡 待机 | 工作中心启用但当前无在制工序 | 工作中心 active，但没有进行中的工序 |
| ⚪ 离线 | 工作中心停用 | 工作中心状态非 active |

> 💡 **设备要亮成「运行中」，需要报工**：光「下达 + 开工」工单还不够——只有某道工序收到**合格数 > 0 的已确认报工**后，它才会从「待开工」进入「进行中」，对应工作中心才会亮起并显示当班任务。

#### 7.6.2 订单详情与材料清单

点右侧列表里的某个订单，进入**订单详情**：

- **产品 × 计划数量**、优先级、完工数、逾期天数
- **双口径进度条**：完工入库口径（完工数 ÷ 计划数）+ 报工口径（工序完工进度）
- **物料齐套**：该工单对应 BOM 展开的**逐行材料清单**（物料名 + 编码 + 已领数/需求数 + 单位），齐套显绿点、缺料显红点
- **工序进度时间线**：每一道工序的名称、所属工作中心、状态（待开工/进行中/已完工/已取消）与完工/计划数

> 💡 **材料来自对应 BOM**：工单下达时系统按所选 BOM 展开生成材料行，领料过账回写已领数，这里展示的就是这套展开结果。

| **货车** | 运输车辆 | 绑定「货车」主数据（生产制造 → 货车管理） |

在布局编辑模式下，可**新增、拖拽摆放、重命名、绑定业务数据、删除**这些对象，位置与绑定关系都会**持久化保存**，下次打开保持不变。

#### 7.6.4 布局编辑（拖拽摆放）

点顶部 KPI 条左侧的「**编辑布局**」按钮，进入布局编辑模式：

1. **拖动**工作中心设备或场景对象到任意位置（松手即自动保存坐标）。
2. 左侧「添加对象」面板可新增 AGV / 仓储房屋 / 人员 / 货车四类对象。
3. 选中对象后可在面板里**绑定业务数据**、**重命名**、**删除**。
4. 再次点「编辑布局」退出编辑模式，位置与绑定已持久化。

> 💡 布局坐标、场景对象都按**租户隔离**存储，各企业维护各自的车间平面图，互不可见。

#### 7.6.5 使用前置条件

要让驾驶舱完整可用，需先备好以下主数据：

| 前置项 | 维护入口 |
| ---- | ---- |
| 工作中心（设备） | 生产制造 → 工作中心 |
| 工艺路线 + 工序 | 生产制造 → 工艺路线 / 工序管理 |
| BOM（材料清单） | 生产制造 → BOM 管理 |
| 员工（场景对象绑定源） | 生产制造 → 员工管理 |
| 仓库（场景对象绑定源） | 进销存 → 仓库管理 |
| AGV / 货车（场景对象绑定源） | 生产制造 → AGV小车 / 货车管理 |

> ⚠️ **工作中心必须先维护**：设备视图以工作中心为主数据源，工作中心为空时 3D 场景里没有设备可显示。

### 8.4 BAQ 查询设计器（图形化）

**BAQ（业务活动查询）** 是一个**不写 SQL** 的可视化查询设计器：像搭积木一样选主表、关联表、字段，配置筛选与排序，发布后可作为**页面设计器**的数据源，也能被 **AI** 调用。

入口：系统管理 → BAQ 管理（`/system/baq`）。

设计器共 6 个页签：

| 页签             | 作用                                                                          |
| -------------- | --------------------------------------------------------------------------- |
| **图形设计**（默认） | ER 图式可视化：每张表一个卡片，勾选卡片上的字段即加入输出，拖卡片右侧圆点连线关联主子表                          |
| **数据源与关联**     | 经典表格模式：配置主表与关联，关联行可展开编辑多字段条件                                          |
| **输出字段**       | 字段、输出别名、聚合（求和 / 计数 / 平均…）、是否分组                                            |
| **筛选**         | 过滤条件（多个条件之间为 **AND**）                                                       |
| **排序**         | 按输出字段升序 / 降序                                                            |
| **结果预览**       | 点「预览」执行当前查询并展示结果（最多 100 行）                                          |

**图形设计页签操作要点：**

- **选主表**：顶部下拉选主表。下拉与卡片标题都显示**业务名**（如「物料表」），悬停可见完整物理表名。
- **勾选字段 = 输出**：点卡片里的字段勾选框即把该字段加入输出字段；卡片标题会标注「主表」或「N 级」。
- **拖线关联**：从卡片右侧圆点拖到空白处 → 弹出选表窗口新增关联表；拖到画布上已有的表 → 改变它的父表。
- **多级关联**：关联表还能继续关联子表，**支持任意层级**（主表 → 子表 → 孙表 → …）。系统会自动按依赖关系排好 JOIN 顺序，并拦住会成环的连线。
- **多字段关联**：一条关联可包含**多个字段条件**（AND 连接），在右侧「关联」面板或经典页签展开行里编辑；点「⚡ 匹配同名字段」可一键补齐两端同名的业务字段。
- **非主外键关联**：条件两端可**任选任意字段**，不限于主外键。例如用物料的 `code` 关联销售订单明细上的物料 `code`——**外键关联只是系统给出的默认值，可以改**。外键列会标注「外键」。
- **添加数据表**：把一个尚未入画布的表加进来，系统按外键自动挂到合适的父表下。
- **自动发现关联**：用外键元数据补全空着的关联字段，并提示还有哪些存在外键关系但尚未加入画布的表。
- **从画布移除表**：会把挂在它下面的**整棵子树**一起移除（避免留下非法关联）。
- **适应画布**：一键缩放，让所有卡片可见。

> 💡 表名默认**去掉多租户物理后缀**（如 `_s_xxxxxx_b`）显示，便于阅读；实际查询仍使用完整物理表名，不影响结果。

> 💡 **自关联**（同一张表父子结构，如 `parent_id`）不支持直接拖线，请用「添加数据表」加入同表的**第二个别名**再连。

> ⚠️ **发布即生效**：BAQ 由「草稿」变为「已发布」后，引用它的页面与 AI 立即使用新定义；改动关联条件前请确认没有页面正在依赖。

**结果预览**已并入设计器页签：点「预览」会保存当前定义并执行查询，结果在末页显示（最多 100 行）；预览成功会自动切到结果页签。

> 🤖 **AI 生成同样支持**：让 AI「创建 BAQ」时，也能生成多级关联、多字段关联与非主外键关联的配置草稿（见 9.2）。

## 8.5 页面设计器（可视化看板与大屏）

**页面设计器**是一个面向业务人员的可视化搭建工具：不用写代码，**拖拽组件 + 接入数据**，几分钟就能拼出一块数据看板或大屏；**发布后自动成为左侧菜单的一项**，有权限的人都能打开查看。它是把 BAQ 查询、业务数据变成"看得见、随时刷新"的画面的入口。

**入口**：系统管理 → 页面设计器（`/system/page-designer`）。

### 8.5.1 界面三块

| 区域         | 作用                                                       |
| ---------- | -------------------------------------------------------- |
| 顶部工具栏     | 页面名称、页面描述、页面切换 / 新建、预览、保存、发布、删除页面                   |
| 左侧组件库     | 所有可拖拽的组件（文本、指标、图表、表格、实时流、提示等）                         |
| 中间画布      | 网格化画布，组件可拖动位置、拖角缩放                                     |
| 右侧属性面板    | 选中组件后显示其属性（标题、数据源、样式等）；面板顶部以只读形式展示该组件的"类型"，方便识别 |

### 8.5.2 第一步：新建与切换页面

1. 在顶部先填写**页面名称**与**页面描述**。
2. 用「页面」下拉切换已有页面，或选「新建页面」开一个空白页。
3. 每个页面在发布前都是**草稿**，仅你自己可编辑、可预览。

### 8.5.3 第二步：把组件放到画布上

- 从左侧组件库**点选**组件，即添加到画布；在画布上拖动可移动、拖角可缩放。
- 选中组件后，右侧属性面板可改**标题、数据源、外观**等；面板顶部以只读方式显示它的"组件类型"。
- 不需要的组件：选中后通过属性面板里的删除（或画布上的删除按钮）移除。

### 8.5.4 组件库一览

| 类别       | 组件       | 适合呈现什么                                       |
| -------- | -------- | -------------------------------------------- |
| 文本与基础   | 文本       | 说明性文字、标题、备注                                  |
|          | 分割线      | 页面上的视觉分隔                                     |
|          | 时钟       | 实时时间，适合大屏角落                                  |
|          | 滚动播报     | 横向滚动的文字条（不带边框与标题），适合播报通知、标语                    |
| 指标与图卡   | 统计数值     | 大号数字卡片，如销售额、在产工单数，可带趋势                         |
|          | 进度环      | 环形进度，如计划完成率、良率                              |
|          | 仪表盘      | 指针式仪表，如产能负荷、设备利用率                            |
| 图表       | 折线图      | 随时间变化的趋势                                     |
|          | 柱状图      | 分类对比                                         |
|          | 饼图       | 占比构成                                         |
|          | 散点图      | 分布 / 相关性                                     |
|          | 图表联动     | 柱 + 线双轴，点击某类可联动高亮，适合探索式分析                     |
| 列表与排行   | 表格       | 明细清单                                         |
|          | 轮播表      | 自动循环翻页的表格，适合大屏滚动展示                            |
|          | 排行榜      | 按数值排序的名次榜，如产量 TOP10                           |
|          | 实时明细流    | 最新记录从顶部不断流入的流水，适合监控                           |
| 实时与提示   | 告警提示     | 醒目横幅，突出预警 / 异常                                |
|          | 状态标签     | 用不同颜色标识状态（正常 / 预警 / 异常）                        |
| 交互       | 按钮       | 可点击，跳转到链接或触发动作                               |

> 💡 滚动播报、统计数值、仪表盘、进度环在预览与发布后**不显示卡片标题**（更贴近大屏的视觉），其余组件仍保留标题作为说明。

### 8.5.5 第三步：给组件接上数据

组件支持三类数据源：

| 数据源          | 说明                                       |
| ------------ | ---------------------------------------- |
| 静态数据         | 直接填写示例数据（一组记录），适合固定文案或临时演示                |
| 业务数据表        | 直接选择系统中的业务表                               |
| BAQ 查询（推荐）   | 指向你在「BAQ 管理」里设计好的查询，可复用、好维护，也方便 AI 调用       |

- 接好数据源后，把**"维度字段 / 数值字段 / 系列字段"**映射到组件（例如柱状图的横轴、纵轴、分组）。
- 没有合适的 BAQ？可以先到 BAQ 管理临时建一个，或让 AI 帮你建（见下一步）。
- **自动刷新**：对动态数据，可在属性里设置"自动刷新（秒）"。组件会按间隔自动拉取最新数据，刷新过程不打断你正在看的画面。

### 8.5.6 第四步：预览与发布

| 动作       | 作用                                                   |
| -------- | ---------------------------------------------------- |
| 预览       | 点顶部「预览」（眼睛图标）弹出预览抽屉，所见即所得，但不可编辑——用于检查效果                  |
| 发布       | 点「发布」后，页面成为左侧菜单里的一项（路径 `/custom/xxx`），有权限的人都能打开         |
| 删除页面     | 点顶部「删除页面」。**系统会先检查是否被引用**：若页面已发布并在菜单中生成入口，会被阻止删除（避免菜单失效）；未引用的页面可直接删除。要删一个已发布的页面，请先到「系统管理 → 菜单管理」移除对应菜单项 |

> 💡 草稿仅你自己可见可改；发布后才对全员可见。发布前多用预览检查布局与数据。

### 8.5.7 第五步：让 AI 一句话建看板（亮点）

打开右上角 AI 助手，用自然语言说一句即可，例如：

> "帮我创建一个生产车间看板，随时查看生产进度、产能状况、缺料状况。"

AI 会自动完成：

1. 设计页面布局，挑选合适的组件；
2. 为缺少数据的组件**匹配或自动创建所需的 BAQ 数据源**（自动创建的 BAQ 会在备注里写明"由 AI 页面设计助手创建、供某页面使用"，方便你识别，也防止误删）；
3. 把数据源字段**自动接到组件**上；
4. 生成一份**草稿页面**。

AI 回复里会给出**可点击的链接**：页面预览、在设计器里编辑、以及跳到 BAQ 管理页查看 / 修改自动创建的查询。你在设计器里微调、满意后点「发布」即可。

### 8.5.8 典型应用场景

- **车间看板**：生产进度、产能负荷、缺料预警。
- **经营驾驶舱**：核心 KPI 汇总（销售额、应收、库存周转）。
- **库存预警大屏**：告警横幅 + 状态标签 + 实时明细流。
- **质量月报**：合格率、报废 TOP、趋势折线。

### 8.5.9 使用贴士

- 动手前先想清楚"要展示哪些指标、给谁看"，再选组件。
- 数据源优先用 BAQ：复用性强、后续好维护、也方便 AI 调用。
- 凡是动态数据，记得设置**自动刷新**间隔，否则只在打开时取一次。
- 大屏建议用深色主题更醒目；系统支持中文 / 英文、浅色 / 深色，页面会自动跟随你的界面设置。

## 9. AI 智能助手

### 9.1 怎么用

点顶栏 **🤖 AI 图标** → 右侧弹出对话抽屉。输入自然语言即可。

对话抽屉顶部可切换**技能**（决定 AI 往哪个方向理解你的话）：

| 技能         | 用途                 |
| ---------- | ------------------ |
| **自动**     | 由系统判断意图（推荐默认）      |
| **数据分析**   | 查数、算指标、找异常、给结论     |
| **创建业务**   | 新建业务单据             |
| **业务动作**   | 对已有单据做动作（过账、审批、转单） |
| **创建 BAQ** | 用自然语言生成 BAQ 查询配置   |
| **普通对话**   | 通用问答               |

### 9.2 能力一览（含示例话术）

| 能力          | 你可以这样说                      | 系统会做什么                                  |
| ----------- | --------------------------- | --------------------------------------- |
| **数据问答与分析** | "帮我分析本月应收应付风险"、"哪些物料低于安全库存" | 识别分析意图 → 查询**你的真实租户数据** → 输出指标、异常、成因与建议 |
| **自然语言建单**  | "建一张采购订单给上海钢铁，物料 A 100 个"   | 抽取字段 → 把名称解析成 ID → **先出草稿** → 你确认后才落库   |
| **单据动作**    | "把这张采购订单过账"、"驳回这张单"、"转成入库单" | 调用单据状态闸门执行；订单类会自动改为"先转单"                |
| **多步计划**    | "新建客户，然后给它开一张销售订单"          | 拆成多步计划依次执行，前一步结果自动传给下一步（最多 5 步）         |
| **知识问答**    | "入库流程应该怎么走"、"XX 制度怎么规定"     | 从知识库做**向量检索**，回答附来源                     |
| **BAQ 生成**  | "我要查各客户的销售额汇总"、"用物料编码关联销售订单里的物料编码" | 生成 BAQ 配置草稿（支持多级 / 多字段 / 非主外键关联），确认后保存      |
| **上下文指代**   | "把它也改成已审批"、"刚才那单呢"          | 记忆中的焦点对象支持"它/这个/刚才那单"                   |

### 9.3 知识库与 AI 问答

**入口**：系统管理 → 知识库管理。三个页签：

| 页签       | 用途                   |
| -------- | -------------------- |
| **文档管理** | 手工新建/编辑知识文档（标题 + 正文） |
| **批量导入** | 粘贴 JSON 批量导入         |
| **文件上传** | 上传文档文件，系统自动抽取正文并入库   |

**支持的文件格式**：

| 格式                                             | 说明                             |
| ---------------------------------------------- | ------------------------------ |
| `.docx`                                        | 支持（自动抽取正文）                     |
| `.pdf`                                         | 支持                             |
| `.txt` `.text` `.md` `.markdown` `.log` `.csv` | 支持                             |
| `.doc`                                         | ❌ **不支持**，请先用 Word 另存为 `.docx` |

上传规则与提示：

- 单次最多 20 个文件，单文件不超过 20MB。
- 逐个文件返回结果：成功则显示标题、字数；**部分失败不影响其他文件**。
- 正文超长会被截断（保留前 20 万字）并标记。
- 上传完成后，系统**只对本次新增的文档建索引**（不会重算全库），速度更快、更省资源。
- 若企业制度文件是中文传统编码，系统会自动尝试正确解码。

**问答降级行为**：如果系统未配置**向量模型**，知识库问答**仍然可用**，只是会退化为关键字匹配（语义召回效果变弱）。建议在 系统设置 → AI 设置 中配置一个向量模型。

### 9.4 安全底线：两段式写库确认

**AI 绝不会在你没确认的情况下写业务数据。**

```
你下达指令 → AI 生成草稿（写入待处理区，30 分钟有效）
          → 你回复「确认」→ 才真正执行
```

- 草稿绑定**你的账号 + 你的租户**，他人不可执行。
- 草稿**只能执行一次**，重复提交会被拒绝（天然防重复过账）。
- 所有 AI 动作都会写入审计日志。
- AI 的权限**不超过你本人**：服务端从角色表读取你的真实权限，不采信对话中的声明。

## 10. MCP 接入（外部 AI 客户端）

**用途**：让 Claude Desktop / WorkBuddy / Cursor 等支持 MCP 协议的客户端，**直接调用你的 ERP**。

### 10.1 使用步骤

1. 点顶栏 **🔌 Api 图标** → 打开「MCP 接入指引」。
2. 切到 **「我的密钥」** 页签 → 点「生成新密钥」。
3. ⚠️ **明文密钥只显示一次**，服务端只保存摘要，请在弹窗内立刻复制保存。
4. 按指引页给出的配置说明，把服务地址与密钥填进客户端的 MCP 配置。
5. 重启客户端即可。

### 10.2 能做什么

| 类别          | 工具                                        | 说明       |
| ----------- | ----------------------------------------- | -------- |
| **只读（6 个）** | 列出实体、查看实体结构、统计记录数、财务摘要、业务分析、知识库检索         | 安全，可直接调用 |
| **单据（4 个）** | 查询单据（只读）、**新建单据草稿**、**单据动作草稿**、**提交单据草稿** | 写操作分两步   |

### 10.3 写操作为什么是两步

MCP 客户端里没有"回复确认"这一轮对话，所以写入被拆开：

```
第 1 步：调用「新建单据」或「单据动作」→ 只生成草稿，返回 action_id，业务表不变
第 2 步：确认无误后调用「提交单据草稿」→ 才真正写库
```

- 草稿 **30 分钟内有效**，**只能提交一次**，重复提交被拒绝 → 不会把单据过账两次。
- **不提供删除能力**。

### 10.4 密钥安全

- 每把密钥**归属签发它的账号**，能访问的数据范围与该账号**完全一致**。
- 密钥与网页登录态**互相独立**：吊销密钥不影响网页登录。
- 支持查看状态与**最后使用时间**，可随时吊销。
- **请勿多人共用一把密钥** —— 无法单独停用其中某个人。
- 密钥生成依赖浏览器的安全上下文，必须通过 **HTTPS 或 localhost** 访问系统。

## 11. 典型端到端业务场景

### 场景 A：采购收货入库

```
① 进销存 → 采购订单 → 新增（选供应商、物料、数量、单价）
② 保存草稿 → 提交 → 审批通过（状态：已审批）
③ 点「下推」→ 生成采购入库单（数量自动带出）
④ 采购入库单 → 填批次/有效期（若物料启用批次）→ 提交 → 审核
⑤ 点「过账」→ 库存增加 + 自动生成会计凭证
⑥ 财务侧核对：应付账款、存货科目余额
```

### 场景 B：销售发货

```
① 进销存 → 销售订单 → 新增（选客户、物料、数量、单价，可选预占库存）
② 提交 → 审批通过
③ 点「下推」→ 生成销售出货单（明细会展示可用库存）
④ 出货单 → 提交 → 审核 → 「过账」→ 库存减少 + 凭证
⑤ 财务侧核对：应收账款
```

### 场景 C：生产制造全流程

```
① 生产制造 → BOM 管理 / 工艺路线 / 工作中心（首次需先备好）
② 物料计划参数 + 工作日历 + 班次（计划基础）
③ 生产订单 → 新增（产品、数量、BOM、工艺路线、领料仓）
④ 勾选订单 → 顶部「下达」（自动生成工序 + 预占材料）
⑤ 顶部「开工」
⑥ 领料单 → 审核 → 过账（材料出库）
⑦ 生产报工 → 逐工序录入合格数/报废数/工时
⑧ 完工入库单 → 审核 → 过账（成品入库）；如需 FQC 先做检验判定
⑨ 生产退料（有剩余材料时）
⑩ 成本核算 + 生产报表 查看工单成本与进度
```

### 场景 D：月末结账

```
① 进销存：确认所有出入库单据已过账
② 存货对账：核对库存金额与总账存货科目是否一致
③ 财务：计提折旧（固定资产）、录入调汇与费用凭证
④ 财务：凭证过账 → 试算平衡校验借贷是否平衡
⑤ 总账余额 / 科目明细账 复核
⑥ 会计期间 → 关闭本期期间（关闭后不可再记账）
```

## 12. 常见问题与排错

| 现象                              | 原因与处理                                                          |
| ------------------------------- | -------------------------------------------------------------- |
| **单位下拉是空的**                     | 「计量单位」主数据没维护。到 系统管理 → 计量单位 添加，**不要**去数据字典找                     |
| **点过账报"会计侧错误"**                 | 存货科目映射未配置完整。先到 进销存 → 存货科目映射 补齐。⚠️ 注意：会计侧问题**不会阻断库存过账**，库存会照常生效 |
| **下推按钮灰色 / 不可用**                | 源单状态不在允许范围内（需先审批通过）。检查单据状态是否为「已审批 / 部分收货 / 部分发货」               |
| **下推提示超量**                      | 该行累计已转数量已达上限，系统按台账防超下推。请核对已转数量                                 |
| **生产订单下达报 `No active routing`** | 该产品没有**已启用且在有效期内**的工艺路线，或工艺路线下没有工序明细。先去 工艺路线 维护                |
| **已过账单据改不了**                    | 正常行为。请先**反过账**，修改后再重新过账                                        |
| **期初库存提示一个仓库只能一份**              | 该仓库已有已过账期初单。先反过账原单                                             |
| **知识库上传 `.doc` 报错**             | 系统不支持旧版 `.doc`。请用 Word 另存为 `.docx` 后再上传                        |
| **AI 说"要确认"，但我找不到确认入口**         | 回复"确认"即可；或在对话中点击确认按钮。草稿 30 分钟内有效                               |
| **AI 查不到某个数据**                  | AI 的权限不超过你本人。确认你的角色是否有该菜单/表的权限                                 |
| **MCP 客户端连接失败**                 | 检查密钥是否复制完整、是否已吊销/过期，以及客户端 env 是否配置正确；错误提示不会静默降级，对不上就直接拒绝       |
| **同一工作中心，两个页面产能不一样**            | 已知差异：生产报表按「工作日 + 班次」计算产能，MPS 粗能力（RCCP）按自然日计算                   |
| **批次过期了但预警里没有**                 | 已知口径：**同时被冻结又过期**的批次优先判为冻结，不进效期预警。请用批次管理页的「已冻结」筛选              |
| **界面变成英文了**                     | 顶栏 🌐 图标切回「简体中文」                                               |
| **当前会计期间无法记账**                  | 该期间已关闭。到 会计期间 检查期间状态                                           |

### 13.3 术语表

| 术语                    | 含义                                   |
| --------------------- | ------------------------------------ |
| **过账（Post）**          | 让单据真正生效：更新库存、生成会计凭证。过账后单据锁定，需先反过账才能改 |
| **反过账（Reverse Post）** | 撤销过账效果，单据退回未过账状态                     |
| **下推 / 转单（DocFlow）**  | 由源单生成下游单据，数量受台账控制，防止超量               |
| **台账（Ledger）**        | 记录"已转多少"的追加式账本，只增不删，冲销用负数行表示         |
| **DocType**           | 单据类型元数据，定义单据的形态与行为                   |
| **工作流（Workflow）**     | 审批流转定义，与"单据能转成什么"（DocFlow）是两件事       |
| **BAQ**               | 业务活动查询，可视化拼装的查询配置（图形化 ER 设计器）        |
| **UoM**               | 计量单位                                 |
| **本位币**               | 全站核算基准币种，全局唯一                        |
| **冻结汇率**              | 汇率保存在单据上，后续汇率变动不影响该单据                |
| **期初**                | 开账数据，不计入本期收入                         |
| **预占库存**              | 订单下达时预留库存，防止超卖                       |
| **RCCP**              | 粗能力计划（MPS 页签）                        |
| **WIP**               | 在制品                                  |
